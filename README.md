# VoiceSaathi 🇮🇳

### Your Voice. Your Access.

**VoiceSaathi** is a voice-first, multilingual civic-tech assistant designed to make everyday digital interactions and government-service guidance simpler and more accessible.

The vision is to help people interact naturally using their preferred language instead of depending entirely on typing, complex forms or technical knowledge.

## 💡 The Problem

Many people face barriers when using digital platforms:

- Language barriers
- Limited digital literacy
- Difficulty navigating complex online forms
- Dependence on typing and text-based interfaces
- Difficulty understanding government-service procedures

## 🚀 Our Solution

VoiceSaathi aims to provide a conversational voice-first experience where users can speak naturally, receive spoken guidance and navigate supported digital tasks step by step.

## ✨ Key Features

### 1. Everyday Voice Assistant
- Conversational voice interaction
- Spoken responses
- Simple explanations and guidance

### 2. Multilingual Experience
- English
- Telugu
- Tamil
- Hindi

### 3. Government Service Guidance
- Guided Income Certificate application demonstration
- Eligibility and document guidance
- Step-by-step application assistance

### 4. Learning and Information
- Easy-to-understand explanations
- Everyday information assistance
- Voice-based learning support

### 5. User Experience
- Responsive interface
- User dashboard
- Conversation and demo history
- Accessible, simple navigation

## 🛠️ Technology Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Lucide React
- Browser Web Speech APIs
- Docker
- Nginx

## 🧪 Current Prototype

The initial prototype includes a guided Income Certificate demonstration with six questions and a completion screen.

Voice interaction, multilingual speech support and additional assistant capabilities are being developed.

**Important:** VoiceSaathi is an independent prototype. It does not represent a government department, and its demonstration does not submit real government applications.

## 💻 Run Locally

```bash
git clone https://github.com/VigneshKumar2711/VoiceSaathi.git
cd VoiceSaathi
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

## 🔐 Privacy and Safety

- Use sample information while testing.
- Do not enter sensitive personal information.
- No real government application is submitted through the current demo.
- Browser speech recognition support and processing may vary by browser.

## 🎯 Project Vision

To make digital assistance more approachable through natural voice interaction, regional-language accessibility and simple guidance.
